# VedRith V1 — Launch Merge Release

This release combines:
1. the working VedRith V1 application foundation, and
2. the original premium VedRith visual design language.

## Important
Before pushing/deploying:
- run `npm ci`
- run `npm run lint`
- run `npm test`
- run `npm run build`

Then perform live QA on:
- Home / auto-location Panchanga
- Panchanga page
- Kundali generation
- English/Kannada switching
- Share Card JPG download
- PWA install/update
- Supabase persistence
- Admin/Event security
- Contact
- Mobile
